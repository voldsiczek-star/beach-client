# Beach Client

Launcher Minecrafta dla Linuksa z wbudowanym modem Beach Client.

## Pobieranie

**[Pobierz najnowszą wersję](https://github.com/voldsiczek-star/beach-client/releases/latest/download/BeachClient)**

Po pobraniu:

```bash
chmod +x BeachClient
./BeachClient
```

Przy pierwszym uruchomieniu launcher dodaje się do menu programów i można go przypiąć do paska zadań.

## Aktualizacje

Launcher sam sprawdza nowe wersje. Gdy jakaś się pojawi, w pasku tytułu jest przycisk **Aktualizuj**,
a po pobraniu **Uruchom ponownie**. Każda wersja jest podpisana - launcher nie zainstaluje pliku z innym podpisem.
